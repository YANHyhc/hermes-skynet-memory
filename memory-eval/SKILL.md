# 记忆系统评测方法论 / Memory System Evaluation Methodology

> 评测 = 体检，方法论 = 处方。报告给系统优化，方法论给LLM完美应用。

## 1. 评测框架 (通用)

```
【6模块×3难度×13指标】:
  模块: 基础召回/跨层一致性/时间衰减/语义变体/噪音抵抗/长尾组合
       + 认知(G推理/H更新/I冲突/J串联/K边界) + 元认知(M) + 场景(S) + 压力(P)
  难度: 基础/中等/挑战/极限/地狱
  指标: Recall@k / MRR / nDCG / AnswerF1 / Faithfulness / Footprint / Latency
       + 深度6指标 (跨层/时间/变体/噪音/长尾/组合)
```

## 2. 自适应出题 (从记忆本身生成)

```
【4类出题器】:
  ① 知识库采样: 从记忆源采样 → 生成查询
  ② 语义变体: 同义问法 (测鲁棒性)
  ③ 时间分层: 24h/本周/历史 (测时效)
  ④ 组合长尾: 多条件+小众源 (测边界)

【自适应闭环】:
  每轮评测 → 识别薄弱区 → 下轮聚焦 (题量增加)
  → 越测越准, 持续逼近能力边界
```

## 3. 评测流程 (4步)

```
Step1 生成评测集: memory_question_gen.py --round N
Step2 执行评测: memory_eval.py --round N
Step3 生成方法论: memory_methodology_gen.py --round N (顺序铁律: 报告必须新于评测集)
Step4 消费: 报告(上帝=优化) + 方法论(LLM=完美应用)
```

## 4. 双消费通道

```
① 评测报告 → 系统优化依据 (数据: Recall/MRR/模块得分/薄弱区)
② 方法论skill → LLM完美应用指南 (画像/地图/技巧/流程)
→ 一次评测: 说清系统什么样/怎么优化/怎么完美使用
```

## 5. 普适性

```
评测框架: 通用 (采样/变体/分层/组合)
方法论: 模板化 ({system_name}占位符)
消费链: 醒来读→缓存→使用→降级 (可选, 使用者自决)
→ 换任何记忆系统: 重跑评测 → 自动适配
```

## 6. 命名规范 (记忆档案)

```
格式: YYYY-MM-DD_类型-主题[-序号]
类型: 讨论|指令|修复|交付|评测|拓扑双检|记录|学习|其他
策略: 新建按规范, 旧档案保留 (渐进式)
```

## 7. 注意事项

```
- 零LLM: 关键词匹配 (确定性), 不引入LLM judge
- 顺序铁律: 先评测 → 后方法论 (方法论基于最新结果)
- 边界: 空记忆源降级 (0也是状态)
- 兼容: 旧命名(8位数字)与新命名(连字符)均可检索
```

## 8. 评测报告输出

```
📊 记忆系统评测报告 (第N轮)
  基础指标: Recall@5 / MRR / nDCG / Latency / Footprint
  深度指标: 跨层/时间/变体/噪音/长尾/组合
  分模块+分难度: 全维度得分
  方法论说明 + 消费链条说明 (使用者自决)
  薄弱区: 下轮自适应聚焦
```
